# Reasoning

The dedicated experiment on state retention and synthesis reasoning has not run yet.

The [9 October observations](observations-2026-10-09/README.md) preserve the three exploratory Fieldnote comparisons, their chart sources, measurements and [methodological limits](observations-2026-10-09/METHODS.md). The HTTP comparator had prefix-cache enabled, but synthesis reuse was zero; the deliberately shared-prefix synthesis control is unmeasured. Effective sampling parity and quality equivalence were not established.

The next protocol will separate state reconstruction from application-level context construction, fix synthesis evidence and sampling, verify synthesis prefix-cache hits, and score task quality alongside emitted reasoning. Its code and frozen protocol will live here. The existing Fieldnote/HTTP implementation is under [the memory experiment](../memory/).

These are historical observations, not results from that future experiment. Raw journals are not bundled in this repository.
