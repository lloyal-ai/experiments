# Reasoning

The dedicated experiment on state retention and synthesis reasoning has not run yet.

The [9 October observations](observations-2026-10-09/README.md) preserve the three exploratory Fieldnote comparisons, their chart sources, measurements and [methodological limits](observations-2026-10-09/METHODS.md). The HTTP comparator had prefix-cache enabled, but synthesis reuse was zero; the deliberately shared-prefix synthesis control is unmeasured. Effective sampling parity and quality equivalence were not established.

The primary benchmark will run the full Fieldnote workload: ingestion, source preflight, planning, concurrent inquiries, tool use, recovery when triggered, synthesis and a saved brief. This preserves the composition in which the original difference appeared. Both implementations will use the same UI journey, fixtures, query and budgets, with effective sampling recorded and matched. Fresh sessions will prevent coverage reuse from silently skipping preflight. Plans, tool choices and findings remain generated by each implementation; their differences are part of the application-level result.

The planned arms are Lloyal resident context, the existing LangGraph + HTTP path with prefix-cache enabled, and an idiomatic shared-prefix HTTP variant with measured synthesis prefix-cache reuse. Any deliberate priming belongs in the workload cost. Repeated runs will randomize arm order, retain failures, measure reasoning by stage with one tokenizer, and score answer quality alongside tokens and time. Reproduction on CUDA is a new measurement, not an assumed continuation of the Metal results.

A companion fixed-evidence synthesis experiment will separate state reconstruction from application-level context construction. It will hold evidence and effective sampling constant, record rendered inputs and prefix-cache receipts, and check output quality. The full workload tests whether the observed reasoning reduction recurs in use; the controlled experiment tests possible causes. In particular, the measured native Survey path inherits the shared spine and receives inquiry findings as text—it does not merge every inquiry's private reasoning into synthesis.

The code and frozen protocol will live here. The existing Fieldnote/HTTP implementation is under [the memory experiment](../memory/).

These are historical observations, not results from that future experiment. Raw journals are not bundled in this repository.
